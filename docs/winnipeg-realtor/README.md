# Winnipeg Property Partners Landing Page

This folder contains a standalone HTML landing page for a Winnipeg-based real estate agent. The page highlights the agent's data-backed process, outlines the services offered before an initial consultation, and includes a contact form for prospective buyers, sellers, and renters to request a preliminary analysis.

## Features

- Sticky navigation with smooth scrolling between sections.
- Responsive layout built with Tailwind CSS for a polished, professional presentation across devices.
- Interactive lead form that validates input, enforces a minimum date/time, and provides user feedback without requiring a backend.

To view the page locally, open `index.html` in your browser.
